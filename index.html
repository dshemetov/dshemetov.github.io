Recent Delphi Projects

Saturday, 17th October 2026

Test quote block.

  • Source Name, “Here”.

A large portion of my work at Delphi has involved producing R packages for epidemiological data processing and forecasting. This includes:

  • epidatr - a package for downloading and processing epidemiological data.
  • epiprocess - a package for processing epidemiological data.
  • epipredict - a package for building forecasting models on epidata.

I used these to build data pipelines (in Python and in R) that flowed into forecasting models. I worked with a research team to design and implement our forecasting models. We read through Forecasting: Principles and Practice and Advanced R recently, as a reading group.

I have also built web apps with Django and FastAPI to Epidata API - Swagger UI. I have peered into the depths of data engineering to serve a 2TB versioned dataset in Postgres (and scoped potential migration to a datalake using DuckDB). Might do some technical writeups on this soon.
